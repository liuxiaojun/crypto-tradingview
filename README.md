## 怎么去分析一个陌生的策略
* 直接扔给 AI，让 AI 分析策略开平仓逻辑，并且输出对应的逻辑代码 ， 读懂逻辑之后，采取关注具体使用了哪些工具
* 策略逻辑优化： 简化 / 增加

## 如何写一个新的逻辑：
* 现有策略逻辑，逻辑输出给 ai，并且告知 ai 具体使用的工具（适当参考，不能完全采用）
* debug， 人工去检查代码中的语法错误和逻辑复现错误
* 策略逻辑优化？ ： 因为“正确（头脑中自以为有效的策略）” 的逻辑，不一定经得起数据（回测系统）的检验
