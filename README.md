## 基本概念
* ema函数返回指数加权移动平均值。 在ema中，权重因子呈指数下降。 它使用以下公式进行计算： EMA = alpha * source + （1 - alpha） *
EMA[1], 其中
alpha = 2 / （length + 1）.source
指的是指数移动平均线， alpha = 2 / （长度 + 1）.
*sma函数返回移动平均值，加总求和，再算平均值.
```
sma = ta.sma(close, 20)
plot(sma, color=color.blue, title="SMA")
```
场景： 趋势识别，适合单边趋势。
* ema（指数移动平均线）， 相对
sma
对最近行情的敏感度更强。
```
ema = ta.ema(close, 20)
plot(ema, color=color.red, title="SMA")
```
对新价格更敏感，适合短中期趋势行情。
* wma （加权移动平均线） 用的不多
* smma / rma （平滑移动平均线） 了解即可
* macd （指数平滑异同移动平均线）

## 如何写一个新的逻辑：
* 现有策略逻辑，逻辑输出给 ai，并且告知 ai 具体使用的工具（适当参考，不能完全采用）
* debug， 人工去检查代码中的语法错误和逻辑复现错误
* 策略逻辑优化？ ： 因为“正确（头脑中自以为有效的策略）” 的逻辑，不一定经得起数据（回测系统）的检验
